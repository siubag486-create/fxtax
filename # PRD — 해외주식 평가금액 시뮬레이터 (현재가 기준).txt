# PRD — 해외주식 평가금액 시뮬레이터 (현재가 기준)

## 1. 제품 개요

### 1.1 목적
사용자가 현재 보유 중인 해외주식의 상태를 기준으로,

"지금 내 평가금액이 얼마인데, 여기서 X% 움직이면 내 계좌에 얼마가 찍히는가?"

를 즉시 확인할 수 있는 초간단 계산 도구를 제공한다.

복잡한 환율, 세금, 수수료는 제외하고 순수 가격 변동 시뮬레이션에 집중한다.

---

## 2. 핵심 가치

- 입력 4개만으로 결과 즉시 확인
- 현재 손익(+/-)과 미래 평가금액을 동시에 보여줌
- 투자자가 가장 자주 하는 질문을 바로 해결
- 반복 사용 가능 (목표가 / 시나리오 테스트)

---

## 3. 타겟 사용자

### Primary
- 해외주식 개인 투자자
- 평균매입가와 현재가를 알고 있는 사용자
- 빠르게 목표 평가금액을 확인하고 싶은 사용자

### Secondary
- 국내주식 / 코인 투자자 (확장 가능)

---

## 4. 주요 사용자 시나리오

### 시나리오 A — 목표 수익 확인
1. 사용자 현재가 입력
2. 평균매입가 입력
3. 보유 수량 입력
4. 예상 변동률 +20% 입력
5. 미래 평가금액 확인

### 시나리오 B — 현재 손익 확인
- 입력 즉시 현재 평가금액과 손익 표시

---

## 5. 기능 요구사항 (Functional Requirements)

### 5.1 입력 영역

#### 필수 입력
- 현재 주식가격 (number)
- 평균매입가격 (number)
- 보유수량 (number)
- 예상 변동률 (%) (number, 음수 허용)

#### 입력 UX
- 숫자 전용
- 소수점 허용
- 변동률은 슬라이더 + 직접 입력 지원

---

### 5.2 계산 로직

#### 변수 정의
P0 = 현재가격  
Pavg = 평균매입가격  
Q = 보유수량  
r = 예상 변동률 (%)

#### 계산식

##### (1) 원금 (매입금액)
principal = Pavg * Q

##### (2) 현재 평가금액
currentValue = P0 * Q

##### (3) 현재 손익
currentProfit = (P0 - Pavg) * Q

##### (4) 현재 수익률
currentReturn = ((P0 - Pavg) / Pavg) * 100

##### (5) 예상 미래 가격
futurePrice = P0 * (1 + r / 100)

##### (6) 미래 평가금액
futureValue = futurePrice * Q

##### (7) 미래 손익 (원금 기준)
futureProfit = (futurePrice - Pavg) * Q

##### (8) 추가 손익 변화량
profitChange = futureProfit - currentProfit

---

### 5.3 출력 영역 (우선순위 중요)

#### 가장 크게 표시 (Primary KPI)
- 예상 미래 평가금액

#### Secondary
- 현재 평가금액
- 현재 손익 (+/-)
- 현재 수익률 (%)
- 미래 손익
- 추가 변화 금액
